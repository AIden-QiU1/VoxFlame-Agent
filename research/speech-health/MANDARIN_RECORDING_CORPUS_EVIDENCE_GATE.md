# 普通话录音语料证据门

> 目的：让录音区的题面筛选可复现、可追溯、可替换，不把个人语感或审核人数误当作语言学事实。

## 放行层级

| 层级 | 进入位置 | 判定依据 | 不代表 |
| --- | --- | --- | --- |
| `recording_ready` | 普通话录音区 | 机器语言学校验 + 工程内容安全门 | 已有录音、已完成训练导入 |
| `collected` | 覆盖统计 | 有效音频 + 非空 `target` + 授权/存储契约 | 读音一定正确 |
| `quality_review` | 复录/抽查队列 | 错读、漏读、静音过长、音频不可用等疑似信号 | 可由单人复核、抽样复核或自动规则触发；不阻塞采集 |
| `training_import_ready` | 模型数据集 | 数据集版本、speaker-disjoint 评测、许可和训练门 | 录音区默认状态 |

## 机器可验证硬规则

每条候选必须能输出 pass/fail 及原因：

1. 来源：来源名、URL/句 ID或词典条目、快照/版本、许可线索齐全。
2. 读音：目标音节—声调必须由整词读音或整句拼音计算命中；多音字不能只凭字形推断。
3. 文本：简体中文、现代普通话字符，长度和标点在录音约束内；不含学习包/课程包/培训包/资料包等商业噪声、敏感高风险内容和明显重复模板。
4. 映射：`target`/`coverage_targets`、承载词、任务分区和来源保存在同一条记录中；与现役题库按规范化文本去重。
5. 可替换：fail 的候选不删除原始来源，只替换录音副本，并保留 `rejection_reason` 和生成版本。

默认句长范围是工程起点而不是语言学真理：短句通常保持 7–18 个汉字；若词项或固定评估任务需要更短，必须显式标记 `prompt_type` 和理由。长度、字符和重复门用于控制录音负担与数据污染，不用于判断说话人能力。

## 规则依据与可复现性

每条规则都要标记依据类型，避免把经验阈值伪装成语言学定律：

| 规则 | 依据类型 | 可复现实现 | 允许调整的证据 |
| --- | --- | --- | --- |
| 音节—声调分母 | 语言学/规范资料 | 固定版本的普通话音节表、规范字读音、整词/整句拼音重新计算 | 新版本资料、明确的地域/人群范围 |
| 词项 2–6 字、短句 7–18 字 | 录音工程启发式 | `prompt_type` 分支 + 可执行长度测试；词项不再套用短句门 | 真实用户完成率、重录率、单句时长和错误率的预注册对照 |
| 来源、简体字、商业/敏感污染、重复 | 数据工程/安全门 | 正则、字符集、来源字段、规范化文本哈希和固定 rejection code | 新污染样本、许可变化、误杀回归 |
| 有效音频 + 非空 target | 数据摄取契约 | recording id、音频时长/文件大小、授权 scope、上传状态的字段校验 | 契约版本升级和迁移测试 |
| 错读、漏读、长空白、不可用音频 | 质量诊断 | `quality_status` 分层；自动规则只生成提示，保留原始样本 | 标注样本、阈值 ROC/误报漏报和 speaker-disjoint 评测 |

任何数值阈值都必须同时记录单位、版本、样本范围、停止条件和回退方式。没有这些材料的“更自然”“更有产品价值”“用户负担更小”只能作为待验证假设，不能成为录音前置硬门。

## 不得作为录音前置条件的事项

- 人工 `spoken_text`、ASR 高置信度；
- 没有标尺、样本、评定者一致性和可重复函数的“自然度”“产品感”“用户负担”判断；
- 仅凭一次 ASR 错误删除构音障碍样本。

这些信息可以在录音后成为质量诊断或研究变量。录音质量状态固定为 `valid / suspected_misread / suspected_omission / long_silence / unusable_audio`，异常进入复录或抽查，不自动销毁原始音频。

## 依据边界

语言学覆盖分母来自版本化普通话音节—声调参考集、规范字读音和整词读音证据；句子来源优先使用可追溯的普通话教材/测试材料、规范词典例句和许可语料。Tatoeba 等社区语料只能作为候选发现源，必须经过上述机器规则和许可记录；如果没有合适、可证据化的中文承载句，保留缺口比主观编句更诚实。

教材类外部仓库必须逐文件核验实际内容与许可。仅有 GitHub 仓库级 MIT/CC0 标识，不能推导其中转载 PDF、词表翻译或嵌入数据全部可用于产品；只有词表而没有句子/朗读作品的仓库只能作为词汇等级参考，不进入录音区。2026-08-24 核验的两个 HSK 仓库均因此保持 `reference_only`，未增加为生产题面。

本文件是录音区工程门，不声称覆盖所有方言、年龄、病因或临床诊断，也不把“录音题面覆盖”写成模型效果承诺。
