# 普通话语言学覆盖与构音障碍采集基线

- 日期：2026-08-22
- 主题：`speech-health`
- owner：训练工作台 + 数据管线 + CLEAR-VOX-MODEL
- 状态：`synthesized`

## 要回答的问题

- 核心问题：现有题库、已采样本和微调数据是否在语言学上覆盖充分；下一轮应补什么，而不是只追求句子总数。
- 为什么重要：题库数量不能证明音系、合法音节、声调、语流音变或真实沟通任务覆盖；缺少人工实际转写时，也无法判断构音障碍语音究竟提供了什么监督信号。
- 明确不研究：本阶段不把音系覆盖直接解释为模型收益，不把 ASR 结果当医学严重程度，也不自动发布新题库或修改生产采集推荐。

## 根本依据与边界

采集 SOP 只回答现场操作、授权、设备、休息和质检，不定义语言学完整性。语言学覆盖按四层分别审计：

1. **音系库存**：零声母、普通话声母、规范化韵母、四个本调与轻声。
2. **音节系统**：现代常用规范汉字读音涉及的合法无调音节，以及实际出现的音节—声调形式。
3. **连续语流**：声调组合、三声连读、“一/不”变调、轻声、儿化候选、音节首中尾位置与连续朗读。
4. **任务与用户**：固定单字/词、短句、连续朗读、自然表达、跨天 anchor 和真实沟通场景；这层不能由拼音覆盖替代。

“完整覆盖”不等于每项出现一次。审计同时报告：

- `present`：至少出现一次，用于发现硬缺口；
- `robust`：达到版本化的最小重复次数，用于发现长尾不足；当前探索阈值为每项 20 次，不是训练收益门槛；
- 分布与任务覆盖：防止总量被少数文章、说话人或高频音节支配。

## 分区模型

用户只选择一个“今天要完成什么”的主任务；语言学标签可以叠加。两者不得再混成同一层导航。

### 互斥主任务分区

| 主任务 | 用户语言 | 数据用途 | 建议单次负担 |
| --- | --- | --- | --- |
| `baseline_words` | 基础字词 | 建立声韵调与短词基线 | 8–12 条，可随时结束 |
| `targeted_gap` | 补齐声音 | 根据个人/群体缺口推荐自然单字、词和短句 | 5–10 条，不显示术语考试感 |
| `functional_speech` | 常用表达 | 日常、出行、求助、就医、工作与设备真实表达 | 8–15 条 |
| `connected_reading` | 连续朗读 | 停连、轻重音、语速和连续构音 | 每段 20–60 秒，分段显示 |
| `natural_speech` | 自然说话 | 自由词汇、修正、停顿与真实意图 | 30–90 秒，可用中性提示 |
| `anchor_retest` | 稳定复测 | 同材料跨日/跨设备可比 | 3–5 条或 30–60 秒 |

### 可叠加语言学标签

- 声母：逐个声母、发音部位、送气对立、平翘舌对立、`n/l` 等易混对立；
- 韵母：介音、韵腹、韵尾、前后鼻尾、复韵、卷舌化；
- 音节：无调音节、音节—声调、音节位置、相邻音节与跨词边界；
- 韵律：本调、轻声、三声连读、“一/不”变调、停顿、重音、语速；
- 任务：单字、词、短句、段落、自然表达、anchor；
- 产品：场景、理解负担、视力负担、句长、预计时长、敏感内容、授权来源。

456 个 `below_minimum` 目标仍有独立的 [mandarin-below-minimum-reinforcement-plan.json](../../frontend/src/lib/corpus/generated/mandarin-below-minimum-reinforcement-plan.json) 采集调度产物：基础题库调度仍为 835 条题面、2998 个未来采集槽位。另从 346 条低频语境候选中按同一机器语言/安全/长度/来源门放行 291 条新增录音就绪题面，覆盖 116 个目标；它们进入独立 `mandarin-recording-reinforcement-corpus.json`，不把计划槽位误报为已录音。

这里的单位必须保持分离：`current_prompt_hits / prompt_deficit_to_minimum` 描述题面多样性，`planned_recording_slots` 只描述未来采集调度，`actual_confirmed_recording_hits` 当前保持 `null`。重复安排同一题面不会提高题面多样性，也不能在录音完成前提高真实覆盖。455 个默认低频目标的题面多样性仍低于 20 次门槛；后续补写必须继续经过语言学、自然度、用户负担、安全、许可和产品审核。

针对其中 146 个安全题面稀少目标，已用完整 Tatoeba 普通话快照重扫而不是沿用台账中先到的三句，并生成 [mandarin-reinforcement-context-review.json](evidence/mandarin-collection-coverage-2026-08-22/mandarin-reinforcement-context-review.json)。当前保留 346 条唯一待审自然语境、354 个目标—句分配；118 个目标已有每音 3 条候选，28 个目标仍需补写。当前 28 个目标均明确标为专家路线，不把高负担或不规范承载词硬塞进默认录音区；每个 brief 都记录 `reason_category / allowed_evidence / default_recording_policy / next_action`，供普通话语言学审稿人决定确认中性承载词、转边缘专项或保持下线。全部 346 条候选六项审核仍为 `pending`，生产条目为 0。

站内 `/corpus-review` 已将核心缺失审核与低频语境审核做成两个互斥工作区，并直接展示 28 个结构化专家 brief：可按目标音、承载词和拼音搜索，显示还缺几条语境，允许导出独立 authoring worksheet，但不能从浏览器直接写生产题面。`学习包`、成人/犯罪/灾难/污名内容，以及 `挨骂 / 殡仪 / 娼妓 / 排尿 / 奴役` 等不适合默认用户朗读的承载词不会进入引导补写；若过滤后无承载词，目标仍保留在 1242 项台账并按专家路线决定确认中性承载词、转 edge 或保持下线，不通过删除目标伪装完整。

## 语料爬取与进入产品的门禁

1. 只按审计缺口抓取，不按“能抓多少”抓取。
2. 来源先分为：官方/标准、开放语音转写、授权现代文本、真实公共服务场景、目标用户材料；每个来源固定 URL、访问时间、实际文件类型、哈希、许可和不能外推项。
3. 网页正文不能直接上线：先去导航/广告/隐私信息、简体化、分句、长度与认知负担过滤、全局/近重复清理、敏感内容审查。
4. 主分区由任务/语义分类决定；语言学标签由拼音/词典/人工抽检决定。关键词只能做候选召回，不能作为最终准确分区证据。
5. 候选选择用集合覆盖优化：优先补高价值缺口，同时限制单来源、单模板、单音节和单主题占比。
6. 至少进行语言学抽检、目标用户可读性/疲劳测试和许可复核，再进入 `validate` 小流量；未通过不得进默认推荐。

## 微调闭环

```text
题库/实际录音/模型 manifest 覆盖审计
  -> 语言学与质量缺口
  -> 授权语料候选 + 人工复核
  -> 小规模采集（固定 speaker/session/anchor）
  -> 可选 spoken_text 质量诊断 + 音频质量分层
  -> 固定 CDSD baseline 的增量消融微调
  -> overall / worst speaker / severity / 1–3字 / 音系混淆 / 延迟
  -> 目标用户真实沟通成功率与疲劳
  -> adopt / revise / reject
```

停止条件：若补采只提高离线覆盖但固定 speaker-disjoint 评测不改善、最差人群回退、错误插入增加或用户完成率下降，则停止扩大并回退推荐权重；不能以题库数量增长作为成功。

评测结构门禁已实现：`frontend/scripts/validate-mandarin-evaluation-report.mjs`。它只接受包含冻结 speaker-disjoint 测试集、总体/最差说话人/短句 CER、严重度与长度分层、P95 延迟、用户成功/跳过/疲劳指标和回退动作的报告；缺任何一项不能进入 `adopt`。当前没有新的模型收益报告，因此 RF-011 仍为 `validate`，不能宣称微调效果。
