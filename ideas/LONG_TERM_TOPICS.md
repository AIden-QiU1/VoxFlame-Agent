# Long-Term Topics

这里放那些不会在今天就有结论，但值得持续讨论、慢慢调研的问题。

---

## 1. VoxFlame 到底先解决什么问题

现在最需要反复问的，不是“还能加什么功能”，而是：

- 我们是不是在解决一个真实高频的问题？
- 用户为什么会在真实生活里持续使用它？
- 哪个时刻是用户最愿意为我们打开产品的时刻？

当前我认为至少有三个方向值得持续讨论：

- 帮助用户主动沟通，主动开口说第一句话
- 拥有用户长期沟通记忆，并逐渐帮助用户爱上和他人沟通
- 把 Agent、模型、记忆系统真正变成现实场景里的帮助，而不是概念堆叠

## 2. 记忆系统到底应该怎么做

这里不是单纯技术问题，而是产品边界问题：

- 记忆到底记录什么，才真的对沟通有帮助？
- 多模态记忆要不要做，怎么做：音频 / 文字 / 视频 / 图片怎么组合？
- 如果隐私边界很强，只能依赖实时数据，那产品是不是更接近“实时翻译 / 实时重表达”？
- 用户会不会愿意让系统持续记录自己的真实沟通片段？

## 3. 如何吸收外部产品的优点

现在看到的外部参考里，有几个方向特别值得长期看：

- Earzz：软硬件一体、场景声音主动发到听障硬件
- Speechify：把一个强需求场景做得极致直接
- Canary Speech：把声音能力和健康判断结合
- 慕言 / 雀说语训：发音检测、纠正建议、训练体系

核心问题不是“抄哪个功能”，而是：

- 哪些能力可以统一进 VoxFlame？
- 哪些能力适合实时主链路，哪些应该放到训练/复盘侧？
- 怎么利用 Agent 和记忆系统把这些点真正串起来？

## 4. 暂时没有结论的问题

- 实时沟通和长期记录之间的边界，到底怎么画才不会伤害用户信任？
- “帮助用户说清楚” 和 “帮助用户重新爱上沟通” 之间，产品优先级怎么排？
- 硬件是不是必须做，还是先靠手机形态走到足够强再说？
