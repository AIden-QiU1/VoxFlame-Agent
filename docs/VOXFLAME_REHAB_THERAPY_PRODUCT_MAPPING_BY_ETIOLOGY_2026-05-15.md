# VoxFlame 最值得产品化的 5 个正式疗法 / 理论锚点（2026-05-15）

> 这份文档只保留 5 个有正式名称、临床或专业机构常见、能直接转成产品功能的疗法 / 理论锚点。泛泛的“多练、短句、家属配合、错题复练”全部删掉；它们只能作为具体协议里的执行部件。

## 选择标准

一个方向只有同时满足下面 5 条，才进入本文：

1. 有正式名称，不是我们自己编的功能名。
2. 有医院、康复科、言语治疗师、专业协会或研究文献背书。
3. 有明确适用人群和理论机制。
4. 能转成 App / Web 的结构化任务流。
5. AI 可以做记录、分析、个性化和专家复核，而不是空泛聊天。

## 1. MIT / MUSTIM：中风后非流利性失语的音乐化语言启动

**正式名称**

- Melodic Intonation Therapy，旋律发音治疗，MIT。
- Musical Speech Stimulation，音乐语言刺激，MUSTIM，属于 Neurologic Music Therapy 技术体系。

**为什么是强锚点**

这是 ReTalk / 复言中风案例里最有辨识度的核心，不是普通“音乐背景”。MIT 抓住的是：中风后左侧语言网络受损时，用户可能仍保留旋律、节奏、自动化歌句或口号式输出能力。治疗师用音高、节奏、重音、合唱、延迟跟读和提示递减，帮助用户从“唱 / 吟诵”逐步回到功能性口语。

MUSTIM 更强调用歌曲、押韵、吟诵、音乐短语去触发自动化语言输出。它和 MIT 一起，可以做成 VoxFlame 的第一个真正康复锚点。

**VoxFlame 产品化**

```text
功能短句库
  -> 治疗师选择 MIT / MUSTIM 路线
  -> 系统提供旋律、节拍、范例音频和视觉提示
  -> 用户跟唱 / 补全 / 吟诵 / 跟节拍说
  -> 逐步减少音乐支架
  -> 成功短句进入沟通页，可大字展示或外放
```

AI 可以记录：启动延迟、目标短句覆盖率、节奏对齐、提示层级、支架褪去成功率、真实沟通迁移次数。

**边界**

必须专家准入。VoxFlame 不能让用户自己点一个“音乐治疗”就开始训练，也不能宣称替代言语治疗师或音乐治疗师。

## 2. LSVT LOUD：帕金森病的响度与自我校准训练

**正式名称**

- Lee Silverman Voice Treatment LOUD，LSVT LOUD。

**为什么是强锚点**

帕金森病常见声音小、单调、句尾弱、用户自觉音量和听众感受不一致。LSVT LOUD 是帕金森言语治疗里最有辨识度的正式疗法之一，核心不是“说大声点”，而是通过高强度响度训练重新校准发声幅度和自我感知。

**VoxFlame 产品化**

```text
响度校准练习
  -> 持续元音 / 功能短句 / 真实场景句
  -> 实时音量和句尾衰减视觉反馈
  -> 沟通页提示“这句对方可能听不清”
  -> 外放 / 大字展示 / 重说建议
  -> 趋势报告给治疗师复核
```

AI 可以记录：响度、句尾衰减、发声时长、语速、功能句达标率、沟通页听众确认反馈。

**边界**

不要未经授权写“我们提供 LSVT LOUD”。可以做“响度校准助手 / 帕金森沟通可听见训练”，并标注需要治疗师确认强度和嗓音安全。

## 3. Voice Banking / Message Banking：ALS / MND 的表达保全

**正式名称**

- Voice Banking，声音银行。
- Message Banking，信息银行 / 消息银行。
- AAC Pathway，辅助与替代沟通路径。

**为什么是强锚点**

ALS / MND 的核心不是把声音“练回来”，而是在言语能力下降前保留表达自主权。ALS Association、MND Association、NICE 等资料都把语音变化、沟通辅助、声音银行、信息银行和 AAC 作为临床服务和沟通支持的重要组成。

这对 VoxFlame 很重要，因为它和我们的记忆、短语库、TTS、沟通工作台天然相连。

**VoxFlame 产品化**

```text
表达保全工作台
  -> 优先录制姓名、家人称呼、求助语、情绪表达、医疗决定
  -> 保存原声 message
  -> 生成未来 TTS / AAC 可用材料
  -> 高频短语一键展示 / 外放
  -> 随病程从实时语音切换到文字、短语、合成语音
```

AI 可以记录：已保留短句覆盖率、录音质量、重要人物 / 场景覆盖、当前可用输入方式、语音识别可用度变化。

**边界**

这不是康复治疗，而是临床沟通支持和表达保全。必须处理授权、家属访问、声音克隆同意、数据导出和删除。

## 4. PECS：孤独症和复杂沟通需求的图片交换沟通系统

**正式名称**

- Picture Exchange Communication System，图片交换沟通系统，PECS。

**为什么是强锚点**

PECS 不是“放几张图片让用户点”。它是有阶段的 AAC 沟通训练系统：从用图片主动交换想要的东西开始，逐步进入距离、坚持、图片辨别、句条组合和回应问题。ASHA AAC 资料中也把 PECS 作为 AAC 低技术干预方案提到。

对 VoxFlame 来说，PECS 的价值是：它把“非口语 / 少口语用户如何主动发起沟通”做成了很清楚的产品协议。

**VoxFlame 产品化**

```text
图片交换沟通
  -> 动机物选择
  -> 图片换物 / 换活动
  -> 多图片辨别
  -> “我要 + 目标”句条
  -> 沟通伙伴确认
  -> 逐步接入语音外放或文字展示
```

AI 可以记录：主动发起次数、提示层级、图片辨别正确率、句条长度、泛化场景、照护者反馈。

**边界**

PECS 是正式体系，不要把所有图片按钮都叫 PECS。儿童和孤独症用户必须有家长、老师或专业人员参与，不做“纠正社交差异”的表达。

## 5. Speech Intelligibility Treatment / Speech Systems Approach：脑瘫构音障碍的可懂度训练

**正式名称**

- Speech Intelligibility Treatment，言语可懂度治疗。
- Speech Systems Approach，言语系统路径。

**为什么是强锚点**

脑瘫相关构音障碍不适合只做单音纠正。Speech Systems / Intelligibility 路线关注的是真实听众是否听懂，把呼吸、响度、语速、短语长度、重音和停顿当成一个系统来调。它和 VoxFlame 的北极星高度一致：提升陌生人沟通成功率，而不是追求“标准口音”。

**VoxFlame 产品化**

```text
可懂度训练
  -> 基线录音：词、短句、真实请求
  -> 系统观察响度、语速、停顿、短语长度
  -> 专家选择策略：更响 / 更慢 / 分短 / 强调关键词
  -> 功能短句练习
  -> 陌生听众或系统确认是否听懂
  -> 有效策略写回沟通页
```

AI 可以记录：语速、响度、短语长度、停顿位置、目标词覆盖率、听众理解率、用户体力负担。

**边界**

不要包装成“脑瘫治愈训练”。它应该是专家配置的可懂度策略训练，目标是沟通参与和被理解。

## 我们最应该先做哪一个

优先级建议：

1. **MIT / MUSTIM**：最像 ReTalk 的中风康复差异化锚点，产品辨识度最高。
2. **Voice / Message Banking**：和 VoxFlame 记忆、短语库、TTS、沟通页最契合。
3. **LSVT LOUD 启发的响度校准**：声学指标容易自动化，但要避开授权和医疗承诺。
4. **Speech Intelligibility Treatment**：最贴合 VoxFlame“让陌生人听懂”的核心目标。
5. **PECS**：适合 App / 平板 / 家庭场景，但需要更强照护者协作设计。
