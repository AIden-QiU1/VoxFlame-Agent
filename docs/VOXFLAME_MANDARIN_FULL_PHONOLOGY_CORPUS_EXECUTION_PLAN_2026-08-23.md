# VoxFlame 普通话全音系列语料库执行计划

- 日期：2026-08-23
- 状态：执行中
- 核心目标：以普通话语言学覆盖和目标用户可完成性为根本依据，建设可审计、可持续补齐、可安全发布的录音语料库；SOP 只约束采集现场，不定义覆盖完整性。

## 现状与唯一事实源

- 覆盖事实源：`mandarin-coverage-target-ledger.json`，逐项维护音节—声调的题库命中、承载字、现代词、实际读音句证据和产品路由。
- 生产事实源：`mandarin-approved-core-gap-corpus.json`，只接受六项审核全部通过的默认核心词句。
- 边缘专项和争议读音不得混入默认录音；原题库、历史录音、manifest 和原始来源不因补音建设被删除。
- 2026-08-23 已发现台账晚于候选包重建，旧页面数字可能引用不同快照。本计划首先增加同源失败门禁并重建完整链路。

## 分层

1. 音系库存：声母、韵母、四本调、轻声和连续语流现象。
2. 核心音节—声调：现代普通话中有干净现代词承载和实际使用证据，适合低负担默认补音。
3. 边缘专项：合法但罕见、地域、专名、感叹、专业或只有词典证据的形式，需专家批准和用户主动选择。
4. 争议下线：来源本身标疑或缺少干净现代词证据，语言学复核前不生成用户任务。

## 执行切片

1. 同步重建 1242 项台账、核心候选、边缘专项、批准导出和产品状态，禁止不同快照混用。
2. 默认核心不再由“搜到一句话”单独决定，必须有现代词承载与现役/开放句料使用证据；明显商业、性、致死和污名化材料在候选与发布两端拦截。
3. 为每个默认核心硬缺口准备至少三条不同候选，优先短词和 4–12 字自然功能句；未通过六项审核不进入生产。
4. 核心硬缺口完成后，再按 `below_minimum` 缺口和真实录音覆盖增量补强，不用总句数代替分布质量。
5. 小规模采集后补人工 `spoken_text`、speaker-disjoint 消融、用户完成率、跳过率和疲劳指标；不改善真实沟通成功率则回退。
6. 站内审稿台只保存本机草稿和导出审核决定；服务端登录与邮箱白名单控制候选读取，CLI 负责来源快照与六项发布门，浏览器不直接修改生产语料。

## 验收

- 1242 项均可追溯到明确层级，不把边缘/争议形式伪装成默认核心。
- 台账、候选、批准导出、产品状态来自同一来源指纹和目标集合，否则构建失败。
- `学习包 / 课程包 / 培训包 / 资料包` 以及明显不适合默认朗读的内容不能进入正式补音库。
- 页面只展示真实批准数量；候选数量不等于上线数量。
- 所有语料脚本测试、前端类型检查、构建和 AI 文档检查通过。

## 当前执行结果（2026-08-23）

- 263 条核心候选已生成 9 批只读审核工作区，当前来源快照固定为 `2026-08-23T03:34:40.850Z`；88 个默认核心目标均达到 `1 个整词锚点 + 2 个句境`，175 条短句全部附有句内整词与整词拼音证据。
- 已完成首轮用户负担收紧：高频但高负担的词锚点改用同音目标下更中性的现代词，例如 `歹徒 -> 好歹`、`懒惰 -> 掌舵`、`醉醺醺 -> 烟熏`、`挣扎 -> 炸鱼`、`产卵 -> 鹅卵石`、`烫伤 -> 烫发`；挑衅、指人评价、灾难语义和明显翻译腔句加入永久拦截。
- `/corpus-review` 已提供批次导航、搜索、状态筛选、六项逐项判断、本机自动保存与 decision JSON 导出；实体表面、中文优先、无渐变和原生表单语义符合现役设计约束。
- 页面和 API 均受登录保护，审核者还需服务端 `VOXFLAME_CORPUS_REVIEWER_EMAILS` 精确白名单；空白名单默认拒绝。
- decision JSON 合并脚本会拒绝过期快照、未知/重复 ID、非法状态及无说明的改写/拒绝。临时往返验证确认 1 条审核决定只会导出 1 条批准语料，其他候选保持待审。
- 现役题库仍为 9107 条（8771 条外部生成子池 + 336 条人工策划/固定评估项），正式核心补音导出仍为 0；本切片没有删除题库、历史录音、manifest 或原始来源。
- 已为 456 个 `below_minimum` 音节—声调建立缺口驱动的重复采集计划：455 个默认核心目标进入调度，1 个争议目标保持下线；从 9107 条现役安全题库中选出 835 条题面，分配 2998 个未来采集槽位，其中 309 项槽位分配完整、146 项因安全题面稀少只做部分分配。
- 题面多样性与真实录音覆盖严格分开：复用现有题面不会增加题面命中数，计划槽位也不是已完成录音；只有人工确认 `spoken_text` 与音频一致后才能计入真实覆盖。455 个默认低频目标的题面多样性仍低于 20 次门槛，后续需要缺口驱动补写和审核。
- 录音区新增“低频补强”任务组，直接读取轻量产品索引；完整 1.7MB 审计计划不进入浏览器包，页面只加载约 120KB 的题目 ID、目标音和优先槽位索引。原有八个发音部位/韵母/声调小组继续保留。
- 已对 146 个安全题面稀少目标重扫完整 Tatoeba 普通话快照，并建立第二个互斥审稿任务。严格默认用户负担过滤后保留 346 条唯一待审句、354 个目标—句分配；118 个目标已有 3 条候选，28 个目标仍需补写。候选减少只发生在尚未审核的外部候选层，不修改 9107 条现役题库、历史录音或 manifest。
- 28 个结构化专家 brief 已进入审稿台：每个目标记录风险类别、允许证据、默认录音政策和下一动作。当前不把高负担或不规范承载词硬写进默认录音区；专家可确认中性承载词、转入 edge 专项或保持下线。界面支持搜索、浏览和独立导出 authoring worksheet，但不允许直接写生产题面；人工新句仍必须走同一六项发布门。
- 承载词门已从“词典合法”收紧为“适合默认用户朗读”，拦截学习包、成人、犯罪、灾难、污名及 `挨骂 / 殡仪 / 娼妓 / 排尿 / 奴役` 等高负担词。被拦截的音系目标不会删除，而是保留在 1242 项全量台账并进入专家专项。
- 真实录音证据已独立于采集计划：10 个历史 manifest 去重生成 1185 条人工 `spoken_text` 复核项，当前 0 条达到 `approved + confirmed`；另按类别/质量分层抽取 60 条双人复核样本，音频核验为 49 条可访问、11 条缺失，因此完整性门未通过，双人一致性覆盖为 0。录音区只展示该事实，不把 2998 个计划槽位或目标文本命中当作真实录音覆盖。
- 真实录音复核决定已补齐离线收口：`validate-mandarin-spoken-text-review` 校验浏览器导出的决定包，`merge-mandarin-spoken-text-review-decisions` 以精确 `source_generated_at` 做稀疏合并；未提交录音保持原状态，批准项必须同时具备人工文本、确认对应、审核者和时间，且合并产物仍固定 `training_import_allowed=false`。
- 60 条双人样本已产品化为 `/corpus-review/dual-spoken-text`：A/B 审核者通过两组独立服务端白名单分配角色，页面只允许提交当前角色的转写；浏览器导出角色决定后，由 `merge-mandarin-dual-review-annotations` 稀疏合并，不能在一个账号中同时伪造 A/B。一致性、仲裁和音频完整性仍由离线门禁决定，当前样本全部 pending，49/60 音频可访问、11/60 缺失。

## 回退

- 新增台账、候选、标签和产品状态均为旁路生成产物；可回退生成文件和入口，不影响历史录音与上传合同。
